# 入学前学习计划：大模型推理优化、AI Systems 与软硬件协同


## 目标

入学前围绕 **大模型推理优化、AI Systems、体系结构与软硬件协同** 做准备。

希望达到：

1. 理解 Transformer 推理、Attention、prefill/decode、KV Cache 的基本机制。
2. 理解 latency、throughput、TTFT、TPOT、显存占用、带宽瓶颈等推理系统指标。
3. 跑通一个开源推理框架或简单推理 demo。
4. 做一组小实验，观察上下文长度、batch size、量化方式对延迟、吞吐、显存的影响。

## 学习内容

### 1. 大模型推理基础

- Transformer decoder-only 结构
- Attention、Q/K/V
- FFN、LayerNorm、RoPE
- prefill / decode
- token-by-token generation
- KV Cache

### 2. 推理系统性能指标

- latency
- throughput
- TTFT: time to first token
- TPOT: time per output token
- tokens/s
- GPU memory usage
- GPU utilization
- compute-bound vs memory-bound

### 3. 推理框架与实验

- Hugging Face transformers 或 vLLM
- 简单 benchmark 脚本
- 上下文长度实验
- batch size 实验
- 量化方式实验
- 显存和耗时记录

### 4. 软硬件协同视角

- quantization
- sparsity
- low-rank
- KV Cache compression
- PagedAttention
- continuous batching
- data movement
- memory bandwidth
- on-chip memory / cache
